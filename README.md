# ENTP

Class projects, deployed with Vercel.

**Live site:** https://entp-chi.vercel.app

## Projects

- **[What Grade Do I Need?](https://entp-chi.vercel.app/GradeNeededCalculator/)** — works out the score needed on a remaining exam or assignment to reach a target course grade. Source: [`GradeNeededCalculator/index.html`](GradeNeededCalculator/index.html)

## Running locally

Each project is a single `index.html` with no dependencies. Open it directly in a browser; no install or server is needed.

## Deployment

Every push to `main` deploys to the live site automatically.
