# What Grade Do I Need?

A calculator that works out the score a student needs on a remaining exam or assignment to finish a course with their target grade.

**Live app:** https://entp-chi.vercel.app

## Running locally

The whole app is one file with no dependencies: [`GradeNeededCalculator/index.html`](GradeNeededCalculator/index.html). Open it directly in a browser; no install or server is needed.

## Deployment

Every push to `main` deploys to the live app automatically.
